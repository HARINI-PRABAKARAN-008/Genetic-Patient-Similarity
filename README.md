# Genetic Patient Similarity

## Project Description
This project uses Machine Learning clustering
to identify similarities between genetic patients.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- K-Means Clustering
- Hierarchical Clustering
- Flask API
- Streamlit Dashboard

## Features
- Patient similarity analysis
- K-Means clustering
- Hierarchical clustering
- Cluster visualization
- Flask API
- Streamlit dashboard
